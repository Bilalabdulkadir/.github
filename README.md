## 📖 Project Overview

This project investigates the relationship between baseball player performance metrics and salary. Using statistical analysis and machine learning techniques, the study identifies factors that influence player earnings and develops a predictive model for salary estimation.

The project demonstrates a complete data science workflow including data preparation, exploratory analysis, visualization, regression modeling, and performance evaluation.
